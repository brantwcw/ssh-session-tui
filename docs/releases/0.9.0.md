SSH Sessions 0.9 adds **H**: open [Herdr](https://herdr.dev) for the selected row.
On **Local terminal** it starts local Herdr. On a machine it attaches Herdr to
that machine through the selected route, using the SSH alias as the host when
the route has one so its proxy and key settings still apply. **Enter** is
unchanged and opens a plain SSH session.

The first time a device opens Herdr on a machine, the picker asks before
continuing, because Herdr's remote attach may install Herdr there. Only **Y**
confirms. The answer is remembered per machine in a device-local file beside
the other device preferences; the shared catalog is not changed.

Herdr reads SSH aliases from the default SSH config only. A route whose alias
was imported from another config file is refused with a message instead of
connecting somewhere else, and so is any address that is not a plain host,
alias or IPv6 literal. If Herdr exits with an error its message stays on screen
until Enter. The picker never tries another route or a plain SSH session for
you, and never changes this device's saved route.

Herdr is installed separately. Set `HERDR_BIN` to an absolute path if it is not
on PATH. Finding Herdr never launches a program or connects.

Assets are compiled Rust programs with checksums and license notices. Normal
installation requires no Python, Git or Rust compiler. macOS remains beta until
physical desktop use is qualified, and the optional SSH Files companion remains
beta.
